# Certificados — Grupo de Tabagismo

Gerador de certificados de conclusão do Tratamento para Cessação do Tabagismo, no padrão visual da Prefeitura de Joinville · Saúde.

**Usar online:** https://danielholtz.github.io/Certificados/

## Como usar
1. Preencha turma, período, cidade/data e as assinaturas (ficam salvos no navegador).
2. Cole os nomes dos participantes, um por linha.
3. Clique em **PDFs individuais (.zip)** — baixa um .zip com um PDF por participante (A4 paisagem). Ou **PDF único** para todos num arquivo só.
4. Use **Baixar só este** para emitir uma segunda via individual.

## Usar sem internet
O `index.html` é autossuficiente (fontes, imagens e bibliotecas embutidas), então funciona de duas formas:

- **Instalar como aplicativo (Chrome ou Edge):** abra o link acima, clique no ícone de instalar na barra de endereço (ou menu ⋮ → *Transmitir, salvar e compartilhar* → *Instalar página como app*). Ele ganha ícone no computador e abre mesmo offline.
- **Arquivo solto:** baixe o [`index.html`](https://github.com/DanielHoltz/Certificados/raw/main/index.html), salve numa pasta (pode renomear para `Certificados.html`) e abra com dois cliques. Funciona em pen drive ou em computador sem internet.

Tudo roda no navegador; nenhum dado é enviado para servidor.
